# FlightTempo Navigation Asset Directory

This directory stores downloadable en-route navigation datasets:
- `waypoints/`: En-route 5LNC waypoints and terminal fixes
- `navaids/`: VOR, VOR/DME, DME, and NDB facilities (OurAirports / Official AIS)
- `airways/`: En-route airway corridors and segment connections
- `sources/`: Data source metadata, licences, and download logs
