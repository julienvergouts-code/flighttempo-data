# Legacy worldwide X-Plane navigation baseline

The repository now imports the public legacy snapshot from https://github.com/ptsmonteiro/x-plane-navdata.

The upstream README explicitly states that the X-Plane data is published under the GNU General Public License v3.0. The upstream README is retained as UPSTREAM_README.md and the source URL is recorded in source-manifest.json. GPLv3 obligations apply to the source files and any redistributed derivatives.

## Included source files

- earth_fix.dat — global fixes/intersections
- earth_nav.dat — global navaids, including VOR/NDB/ILS-related facilities
- earth_awy.dat — global airway segment source

## Important limitations

- The upstream repository was last updated in 2013. This is a stale legacy baseline, not a current AIRAC.
- Source-cycle headers may be absent or unknown. The importer preserves that status; it does not fabricate an AIRAC cycle.
- Airway endpoint resolution may be incomplete. The import report records unresolved and ambiguous endpoints.
- Legacy airway records may not contain typed endpoints, directional semantics or low/high classifications. Such values remain unknown rather than guessed.
- These files are for personal FlightTempo development and route-engine testing only. They are not an AIP, not an operational flight-planning database and must not be used for real-world navigation.

The importer generates normalized CSVs in navigation/waypoints/, navigation/navaids/ and navigation/airways/. The master app download manifest is regenerated by the importer.
