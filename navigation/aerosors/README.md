# Aero.Sors experimental tables

Generated by `scripts/import_aerosors_tables.py`.

- `vor_ndb.csv`: all non-empty rows from the published VOR/NDB workbook.
- `ils.csv`: all non-empty rows from the published ILS workbook.
- `source-manifest.json`: import timestamp, source workbook hashes, sheet/row counts, source cycle label and limitations.

The export is intended for FlightTempo development testing only. It is not an AIP, is not operationally validated, and does not include the full World FSXP3D BGL package, fixes/intersections, airport/runway scenery records, airways, SIDs, STARs or approaches.

Reviewed terms permit distribution of the original Aero.Sors package unchanged on free media. Explicit permission to republish derived CSVs has not been confirmed. Do not distribute these derivatives to users or use them in production without written permission.
