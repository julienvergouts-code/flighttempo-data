# OurAirports

Provider: OurAirports  
Source: https://davidmegginson.github.io/ourairports-data/  
Licence: CC0 / Public Domain, as stated by OurAirports.

OurAirports provides community-maintained airport, runway and navaid reference data. It is worldwide but is not an official AIS publication and may be incomplete or stale.

No attribution is required under CC0, but source provenance is retained. The legacy airports/airports.csv file contains fields with mixed/under-review provenance; do not assume every column inherits OurAirports' CC0 status.
